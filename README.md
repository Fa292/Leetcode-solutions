# Leetcode-solutions
This repository contains my ongoing journey through LeetCode as I work on improving my problem-solving skills and consistency. For each problem I solve, I include both the initial brute-force approach and a more optimized version whenever possible. This helps me track how my thinking evolves from the simplest workable idea to a cleaner, more efficient solution. Over time, the collection will grow to reflect different patterns, techniques, and insights I pick up as I learn. It also serves as a personal archive I can revisit, compare approaches, and measure how much progress I’ve made. I’ll continue updating it as I solve more problems and explore better ways to approach each challenge.
